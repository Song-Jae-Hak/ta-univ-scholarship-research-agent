# 리서치 에이전트 파이프라인 실행

## 이번 실행 주제
`$ARGUMENTS`
> 비어 있으면 주제는 **`타대학 장학 제도`** 로 한다.

당신은 **오케스트레이터**다. 아래 순서를 그대로 수행한다.

## 0. 준비
- `research/`, `report/` 폴더가 없으면 만든다.
- (참고) 브라우징 도구 `agent-browser`는 `C:\Users\user\.claude\bin\agent-browser.exe`에 전역 설치돼 있다. 헤드리스가 막힌 환경이면 조사원은 WebFetch로 대체한다.
- **주의:** 한글(HWP/HWPX) 내보내기 스킬 파일은 **다른 세션에서 작업 중이므로 건드리지 않는다.** 이 명령의 범위는 목차·스토리라인 확정까지다.

## 1. 조사원 5인 **동시** 실행 (순차 금지, 15분 제한)
**한 번의 메시지에서 5개의 Agent 호출을 동시에** 띄운다(병렬). 각 조사원은 자기 md에 저장한다:
| subagent_type | 담당 | 산출 파일 |
|---|---|---|
| `policy-researcher` | 교육부·한국장학재단 정책·공고 | `research/01_policy.md` |
| `univ-national-researcher` | 거점국립대 교내 장학 | `research/02_univ_national.md` |
| `univ-private-researcher` | 주요 사립대 교내 장학 | `research/03_univ_private.md` |
| `univ-special-researcher` | 특수대학 장학·학비 | `research/04_univ_special.md` |
| `disclosure-researcher` | 대학알리미 장학 지표 | `research/05_disclosure.md` |

각 호출 프롬프트에 반드시 포함: ①이번 **주제**, ②"각 기관 **공식 사이트에 직접 접속**해 수집", ③"**15분** 시간 제한, 초과 전에 반드시 md 저장", ④"모든 수치에 **출처 URL·확인일** 병기, 미확인은 `(미확인)`, 추정 금지".
- 병렬 실행 후 완료 알림을 기다린다. **15분이 지나도 끝나지 않은 조사원은 중단**하고, 그때까지 저장된 부분 결과로 진행한다.
- 5개 md가 모두 생성됐는지 확인한다(누락 시 해당 조사원만 재실행).

## 2. 편집장 종합 (MODE: propose)
`chief-editor`를 `MODE: propose`로 호출한다. 편집장은 `research/*.md`를 읽고 **핵심 발견 / 목차안 / 스토리라인안 / 확정할 논점 3종(반드시 언급할 점·신중히 다룰 점·이야기 순서)**을 제안한다.

## 3. 사용자와 확정 (반드시 대화)
편집장 제안을 사용자에게 제시하고 **AskUserQuestion 등으로 ①반드시 언급할 점 ②가리거나 신중히 다룰 점 ③이야기 순서를 직접 확정**받는다. 편집장/오케스트레이터가 **혼자 정하지 않는다.**

## 4. 최종 저장 (MODE: finalize)
사용자 결정을 담아 `chief-editor`를 `MODE: finalize`로 호출 → **`report/목차_스토리라인.md`** 저장.

## 5. 마무리 보고
생성된 파일 목록(`research/01~05`, `report/목차_스토리라인.md`)과 확정 요약을 사용자에게 보고한다. (한글 파일 내보내기는 다음 단계이며 여기서는 하지 않는다.)
