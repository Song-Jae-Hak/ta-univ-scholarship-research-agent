# pnu-hwpx-report

부산대학교 **「산지니 AI 활용 사례 공모전 추진계획」** 예시 HWPX 와 **동일한 서식**으로
대학·공공기관용 추진계획/공모 안내 보고서를 생성하는 스킬.

원본 예시를 한컴오피스 한글에서 PDF 로 변환해 **한 페이지씩 육안 대조**하여 서식 충실도를 검증했다.

## 구현 서식 (원본 그대로)

- **표지**
  - **제목 배너**: 청록→네이비→검정 **그라데이션 상·하단 바** 사이, 연회색(#F1F1F1) 채움 셀에
    「회차(18pt)」+「제목(24pt HY헤드라인M)」을 가운데 정렬.
  - **날짜**: 페이지 중앙, 22pt 큰 글씨(가운데). 표지 쪽번호는 숨김.
  - **발신부**: 부산대학교 로고 + 「부서명(18pt)」 표(로고 우측 세로선 구분).
- **본문**
  - **절 표제**: `1 2 3 …` **네모 남색(#3E57A5) 박스 흰 숫자** + 제목(17pt, 아래 밑줄).
  - **글머리**: `◦ (라벨) 내용` — 라벨 굵게, 내어쓰기(wrapped 줄 정렬), 하위는 `- 내용`.
  - **표**: 청회색(#DFE6F7) 머리행(굵게) + 머리행 아래 **이중선** + 얇은 내부선 +
    외곽 위·아래 굵은 선. 선택적 **합계행**(연노랑 #FFF7CC).
  - **주석**: `※` 12pt 고딕.
- **붙임**: `붙임 N` **청록(#079FCE) 박스** + 제목(전체 테두리), 새 페이지 시작.
- **페이지**: A4 세로, 하단 가운데 쪽번호(표지 제외 → 본문 1페이지부터).

## 동작 방식

`scripts/build.py` 가 콘텐츠 JSON 을 받아:
1. `assets/header.xml`(폰트·글자 86종·문단 71종·테두리 59종·그라데이션)과
   `assets/image1.jpg`(로고)·스크립트를 **원본 그대로 재사용** → 서식 100% 보존.
2. `Contents/section0.xml`(본문)만 코드로 생성. 표지의 그라데이션 배너·로고 발신부는
   원본 조각(`assets/tpl_title.xml`/`tpl_issuer.xml`)의 텍스트만 치환.
   `linesegarray`(줄 배치 캐시)는 생략 → 한글이 열 때 자동 재계산.
3. `mimetype`(STORED 선두)·`content.hpf`·`META-INF`·`settings`/`version`·`Preview` 와
   함께 zip 패키징.

## 사용법

```bash
python scripts/build.py -c examples/sample_input.json -o 결과물.hwpx
```

출력 JSON 의 `PASS: true`, `문제: []` 이면 정상. (미정의 자원 참조·미치환 placeholder 0 검증)

## 콘텐츠 JSON 스키마

```json
{
  "메타": { "출력_파일명": "보고서.hwpx" },

  "회차":  "2026년 제1회",          // 선택. 제목 위 작은 줄(생략 가능)
  "제목":  "OO대학 AI 리서치 지원 사업 추진계획",
  "날짜":  "2026.  7. ",
  "발신1": "OO대학교 미래교육혁신원",  // 로고 우측 1행
  "발신2": "AI교육지원과",            // 로고 우측 2행(선택)

  "섹션": [
    { "표제": "추진 개요",
      "항목": [
        { "글머리": { "라벨": "추진목적", "내용": "..." } },  // ◦ (라벨) 내용
        { "글머리": "라벨 없는 일반 글머리" },                // ◦ 내용
        { "하위":   "하위 글머리(- 내용)" },
        { "주석":   "※ 로 표시할 단서" },
        { "여백":   true },                                  // 빈 줄
        { "표": {
            "머리": ["구분", "내용", "배점"],
            "폭":   [8000, 29352, 8000],   // 선택(HWPUNIT). 합계≈45352 권장, 생략 시 균등
            "정렬": ["C", "J", "C"],        // 선택. C=가운데, J/L=양쪽. 기본 [C,J,J,...]
            "합계행": true,                 // 선택. 마지막 행을 연노랑 합계행으로
            "행": [
              ["문제정의", "문제를 명확히 정의했는가", "20점"],
              ["시각화", ["결과 전달이 효과적인가", "부가 설명 줄"], "20점"],  // 셀에 여러 줄 → 리스트
              ["합계", "", "100점"]
            ]
          } }
      ] }
  ],

  "붙임": [
    { "번호": 1, "제목": "참가 신청서(작성 양식)",
      "항목": [ { "글머리": "..." }, { "표": { "머리": [...], "행": [...] } } ] }
  ]
}
```

규칙:
- **`섹션`·`항목`·`표.행`·`붙임` 개수 제한 없음** — 자유롭게 늘린다.
- `항목` 원소는 `글머리`/`하위`/`주석`/`표`/`여백` 중 하나를 키로 갖는 dict.
  `{"라벨":..,"내용":..}` 처럼 키가 없으면 ◦ 글머리로 처리.
- `표.행`의 셀 값은 문자열, 또는 **여러 줄이면 문자열 리스트**.
- `표.폭` 합계는 본문폭 **45352**(HWPUNIT ≒ A4 - 좌우여백)에 맞춘다.
- 표는 2열이면 굵은 세로선(0.2mm), 3열 이상이면 얇은 세로선(0.1mm) 스킴을 자동 적용.

## 작업 절차

1. `examples/sample_input.json`(4개 절 + 표 3종 + 붙임 1 예시) 을 복제해 내용을 채운다.
2. `python scripts/build.py -c 입력.json -o 결과.hwpx` 로 빌드 → `PASS: true` 확인.
3. 한컴오피스 한글에서 열어 표지 배너·네모숫자·표 색·쪽번호를 확인한다.
   (LibreOffice 는 HWPX 미지원)

## 로고 교체 (타 대학용)

기본 로고는 부산대학교다. 다른 기관 로고로 바꾸려면 `assets/image1.jpg` 를 **가로로 긴
로고**(원본 1350×340 과 유사한 4:1 비율 권장)로 교체하면 된다. 비율이 크게 다르면
표지에서 로고가 늘어나 보일 수 있다. 로고가 필요 없으면 `tpl_issuer.xml` 의 로고 셀을
비워 편집한다.

## 폰트 의존성

원본은 **HY헤드라인M · 휴먼명조 · 한양중고딕 · 굴림체 · 맑은 고딕** 을 사용한다.
해당 폰트가 없는 PC 에서는 한글이 유사 글꼴로 대체하므로, 원본과 100% 동일하게 보이려면
이 글꼴들이 설치되어 있어야 한다. (구조·색·레이아웃은 폰트와 무관하게 유지)

## 한계

- 한컴오피스 한글에서만 100% 렌더링. 컨테이너에서는 zip·XML·자원 참조 무결성까지 자동 검증.
- 표지 배너/발신부는 텍스트만 치환(레이아웃 고정). 배너 색·로고 위치 등 시각 구조 변경은
  `assets/` 원본 조각을 한글에서 직접 편집해 교체한다.
- 셀 병합(colSpan/rowSpan)은 헬퍼에 있으나 JSON 스키마 미노출(단순 표 위주).
