## A. 핵심 발견 요약 (5개 조사 교차 통합 인사이트)

### A-1. 관통하는 사실: 장학 재원의 65%가 국가장학금
- 전국 4년제(+교육대) 장학 재원 구성: **국가장학금 3조2,858억원(65.0%)**, 교내장학금 1조5,872억원(31.4%), 사설·기타 2.9%, 지자체 0.6% [05]
- 정책 측: 2026년 국가장학 총예산 **5조1,161억원(+1,354억)** [01]
- 현장 측: 거점국립대 5개교 모두 저소득 지원을 국가장학금 구간(0~9)에 연동, 사립대·과기원도 국가장학금 先신청 전제 [02][03][04]
- => **정책·현장·공시 3자 정합**: 국가장학금이 모든 대학 장학의 공통 출발점. "대학 자체 노력"은 총액이 아니라 **교내장학금 비중**으로 별도로 봐야 함 [05].

### A-2. 통념 반전 수치: 1인당 장학금은 사립 > 국공립
- 1인당 장학금(2024회계연도, 2025.8.29 공시): 전체 **382.7만원**, **사립 403.4만원 > 국공립 313.3만원** [05]
- 단, 1인당 **교육비**는 반대로 국공립(2,592.5만) > 사립(1,838.6만) — 두 지표 방향이 반대라 **절대 혼용 금지** [05]
- => "국공립이 더 관대할 것"이라는 통념과 반대. 눈에 띄는 훅(hook)이 될 수 있는 수치.

### A-3. 유형별 구조가 근본적으로 다름 (국립 vs 사립 vs 특수)
- **거점국립대** [02]: 「성적우수(신입생 중심) + 저소득(국가장학금 구간 연동) + 근로」 3종 뼈대 공유, 국가장학금 중심·정액, 이중수혜/등록금초과 금지. 지역연계 장학(부산지역인재, 백엽재단 등) 공통. 조사원 판단: **부산대만의 차별점은 크지 않음**.
- **주요 사립대** [03]: 자체 브랜드 고액·다년 장학(연세특별=전액, 삼성/장영실/다산, 한양 다이아몬드플러스=4~5년 전액, 중앙 다빈치, 이화 E4/W4=8학기 전액). 등급화·브랜드화, 재단·기부금 재원. **유지조건 엄격**(평점 3.5~4.0대, 낙제금지) → 명목 전액과 실제 유지율 사이 괴리 가능(유지율은 미확인).
- **특수대학** [04]: 재원 성격 자체가 다름(기관 설립목적 예산). **스펙트럼 존재** — 국비대(사관/경찰)=선지급·노동상환형(의무복무, 불이행 시 학비 상환: 경찰대 6년/설치법 §9), 과기원=조건부 증여형(성적미달 시 감액, 상환 없음), 특수목적(한예종/교대)=종합대 유사형.

### A-4. 공통 신청구조 리스크: "국가장학금 先신청" 전제
- 사립(한양 사랑의실천, 경희 우정, 이화 복지)·과기원(KAIST 국가장학금 필수신청) 모두 국가장학금 선신청→소득분위 산정→교내장학 배정의 2단계 [03][04]
- => 매 학기 미신청 시 교내장학까지 전액 배제되는 공통 리스크. 신청 프로세스 복잡성이 실질 수혜를 가르는 숨은 변수.

### A-5. 정책–현장–공시의 '괴리·블랙박스'
- **국가장학금 Ⅱ유형**: 전국 공통 금액 없음, 대학 자체 매칭에 좌우 [01]. 그런데 공시에서도 개별 대학 교내/국가/교외 실수치 **전부 미확인** [05] → 대학별 자체 노력을 정량 비교할 1차 근거가 비어 있음.
- **명목 전액장학 vs 유지율**: 사립 고액장학 유지조건 엄격하나 유지율 통계 미확인 [03].
- **"과기원=무료" 통념의 반례**: GIST는 기본장학금에도 실부담 103만원/학기 잔존 [04].

### A-6. 눈에 띄는 개별 수치(근거 확실한 것 위주)
- 국가장학금Ⅰ 1~3구간 연 600만원 / 9구간 연 100만원 (직접 확인) [01]
- 전국 장학총액 5조540억원(최초 5조 돌파) [05]
- 경상국립대: 등록금의 **74.5% 장학 환원, 1인당 평균 301.7만원** — 환원율을 공개한 유일 사례 [02]
- GNU리더스: 등록금 전액 + 생활보조 학기당 400만원 [02]
- 취업후상환 학자금대출 **소득요건 폐지**(2026, 전 대학(원)생 확대) [01]
- 2027학년도부터 학자금지원 **10구간→5구간 개편 예고** [01]

### A-7. 데이터 신뢰도 지형(미확인 분포) — 투명 공개 대상
- 개별 대학 공시 실수치 전부 미확인(대화형 JS 페이지) → 공공데이터포털 CSV(data.go.kr/15038576) 재현 경로 제시됨 [05]
- 사관학교 4곳 공식사이트 접속 실패 → 나무위키 등 2차 출처 의존 [04]
- 과기원 커트라인 출처 불일치(UNIST 3.1~3.7 상이, DGIST 전액면제 여부, GIST 실부담) [04]
- 국가장학금 일부 2차 출처(근로 시급, 다자녀 금액, 우수장학 규모, 대통령과학장학 277명 구성) [01]
- 서강대 전 항목 미확인, 중앙대 다빈치 구(2018)연도 [03]; 강원대·전북대·제주대 부분 확인 [02]

### A-8. 부산대 위치(자기점검·이해상충 대상)
- 확인된 것: 성적우수(Premier·국가우수·성적우수), 학업지원(소득분위), 우선선발(보훈·탈북민·특수교육·형제자매), 근로·장학사정관장학금, 부산지역인재 장학 [02]
- **미확인**: 기숙사장학 유무, 등록금 대비 환원율, 공시 개별 실수치 [02][05]
- 편집장 메모: 사용자 부산대 소속. 오히려 **부산대 데이터가 가장 얕게 확인**됨 → "우호적으로 부각"보다 "동일 잣대 + 공백 솔직 공개"가 편향 방어에 유리.

## B. 목차안(案)

### [본안] 정책 기준선 → 유형별 비교 → 공시 검증 → 교차분석
- **Ⅰ. 서론** — 조사 배경·목적, 5개 축(정책/국립/사립/특수/공시), 확인일(2026-07-24), 방법·한계(미확인 표기 원칙)
- **Ⅱ. 정부 장학 정책의 골격(기준선)** [01] — 국가장학금 Ⅰ·Ⅱ, 근로/다자녀/지역인재, 우수장학, 학자금대출, 2026 정책변화(예산 5.1조, 소득요건 폐지, 2027 구간개편)
- **Ⅲ. 대학 유형별 교내 장학 비교** — Ⅲ-1 거점국립대[02] / Ⅲ-2 주요 사립대[03] / Ⅲ-3 특수대학[04]
- **Ⅳ. 공시 지표로 본 장학 재정** [05] — 지표 정의(1인당 장학금 ≠ 교육비), 재원구성(국가 65%), 국공립 vs 사립 1인당 역전, 개별대학 실수치 공백·재현경로
- **Ⅴ. 교차 분석 — 정합과 괴리** — 국가장학금 중심성 / Ⅱ유형 블랙박스 / 통념 반전 / 신청구조 리스크 / 데이터 공백
- **Ⅵ. 부산대 위치짚기(자기점검)** — 확인·미확인, 이해상충 고지
- **Ⅶ. 결론·후속 조사 과제** — 미확인 목록, 재현 경로(CSV/OpenAPI), 우선순위(서강대·개별 공시수치·사관학교 의무복무)

### [대안] 학생 체감 bottom-up (경량)
- Ⅰ 서론 → Ⅱ "얼마 받나/어떻게 받나"(공시·신청구조 먼저) → Ⅲ 유형별 심층 → Ⅳ 정책 기준선 → Ⅴ 부산대·한계·후속
- 장점: 독자 몰입 빠름 / 단점: 근거(정책)보다 결론이 앞서 논리 부담.

## C. 스토리라인안(案) — 6단계

1. **공통 출발점**: 정부가 깐 기준선 — 국가장학금이 전체 장학 재원의 65%, 2026년 5조원대. 모든 대학 장학은 여기서 시작한다. [01][05]
2. **갈라지는 지점**: 그 위에 대학이 얹는 '자체 노력'은 유형별로 극명하게 갈린다 — 국립(연동·정액·3종) → 사립(브랜드 고액·다년, 엄격 유지조건) → 특수(재원·의무·상환 구조가 근본적으로 다름). [02][03][04]
3. **통념 반전**: 공시 수치는 상식을 뒤집는다 — 1인당 장학금은 사립>국공립. 단 재원의 65%가 국가장학금이라, '자체 노력'은 교내장학 비중으로 따로 봐야 한다. [05]
4. **정합과 괴리**: 정책·현장·공시를 겹쳐 보면 정합(국가장학금 중심성)과 괴리(Ⅱ유형 블랙박스, 명목 전액 vs 유지율, 개별대학 실수치 공백)가 동시에 드러난다. [01][03][05]
5. **자기점검**: 부산대는 이 지형 어디에 있나 — 확인된 것과 확인 못한 것을 솔직하게(이해상충 고지). [02][05]
6. **다음 단계**: 무엇을 더 확인해야 하나 — 미확인 목록과 재현 경로. [01~05]

### ③ 이야기 순서 — 옵션 3
- **옵션 1(정책 top-down)**: 정부 기준선→유형별→공시검증→교차→부산대→후속. 장점: 논리적. 단점: 체감 늦음.
- **옵션 2(학생 체감 bottom-up)**: 얼마/어떻게 받나(공시·신청)→유형별→정책→부산대. 장점: 몰입. 단점: 결론 선행.
- **옵션 3(유형 비교 중심)**: 국립 vs 사립 vs 특수를 전면, 정책·공시는 양옆 근거. 장점: 주제 직결. 단점: 정책맥락 분산.
