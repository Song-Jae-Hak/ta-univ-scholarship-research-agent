# 공시 조사 — 대학알리미 장학금 지표
- 조사원: disclosure-researcher / 확인일: 2026-07-24 / 주제: 타대학 장학 제도

## 1. 장학금 공시 지표 정의·산식

대학알리미(academyinfo.go.kr)는 「교육관련기관의 정보공개에 관한 특례법」에 따라 한국대학교육협의회 대학정보공시센터가 총괄 운영하며, 14개 분야 공시항목 중 '장학금'은 학생/재정 분야에 포함됨.

| 지표 | 정의·산식 | 비고 |
|---|---|---|
| 학생 1인당(연간) 장학금 | **(교내장학금 총액 + 교외장학금 총액) / 재학생 수** | academyinfo.go.kr 대학주요정보 다운로드 페이지 설명 기준 |
| 교내장학금 | 대학 자체 재원(등록금·기금 등)에서 지급. 성적우수/저소득층/근로/재난/교직원/기타 유형으로 세분 공시 | 공공데이터포털 항목 설명 |
| 교외장학금 | 외부 재원에서 지급. **국가**(국가장학금 등)/**지방자치단체**/**사설 및 기타**로 세분 | 국가장학금은 교외장학금의 하위분류 |
| 총장학금 지원율(등록금 대비 장학금 비율) | **학생1인당 장학금총액 ÷ 학생1인당 등록금수입** = [(교내+교외장학금)/재학생수] ÷ [교비회계 등록금수입(단기수강료 제외)/재학생수] | 대학알리미 자체 항목명이 아니라 **한국사학진흥재단 대학재정알리미**(uniarlimi.kasfo.or.kr)가 대학알리미 원자료를 재가공해 제공하는 지표. 대학알리미 내 동일 명칭 공식 지표 여부는 (미확인 — 접근 제약) |
| (구분 주의) 학생 1인당 교육비 | 인건비+운영비+**장학금**+도서구입비+실험실습비+기계기구매입비 등 ÷ 학생수 | 장학금과는 **다른 지표**이며 장학금을 구성요소로 포함. 언론 보도에서 장학금과 혼동되기 쉬워 별도 표기함 |

### 대표 대학 비교 수치 (교내/국가/교외 장학금)
- 개별 대학(서울대·연세대·고려대·성균관대·부산대 등)의 **교내/국가/교외 장학금 실수치는 이번 세션에서 확인하지 못함 (미확인 — 접근 제약)**. 대학알리미가 학교명 검색 후 상세페이지로 진입하는 대화형 구조(JS 렌더링)라 WebFetch 정적 접근으로는 수치가 노출되지 않음.
- 부분적으로 확인된 **참고 수치(장학금 아닌 1인당 교육비)**: 연세대 3,965만원, 고려대 3,315만원, 성균관대 3,242만원 (서울경제 보도, 2025~2026 대학알리미 기준 추정 인용). 장학금 수치가 아니므로 본 조사 목적(장학금 비교)에는 **직접 사용 불가** — 참고용으로만 병기.
- 부산대 개별 수치: (미확인 — 접근 제약). 아래 3장 경로로 직접 조회 필요.

## 3. 데이터 확인·다운로드 경로(재현 방법)

1. **대학알리미 공식 사이트 (1차 출처)**

   - 개별 대학 상세: 메인 → "대학별 공시정보" 또는 학교명 검색 → 해당 대학 페이지 → '학생' 또는 '장학금' 탭에서 "장학금 수혜 현황" 확인 (대화형 조회, 학교명 입력 필요 — 자동화 접근 제약으로 이번 세션에서는 직접 수치 미추출)

## 4. 한계·미확인 항목

- **대학알리미 공식 "장학금" 공시 지표의 편람상 정확한 조문(산식의 1차 원문 캡처)**: 이번 세션에서 「대학정보공시 편람/지침서」 원문 PDF를 직접 열람하지 못함. 위 정의는 academyinfo.go.kr 다운로드 페이지 설명 및 공공데이터포털 메타데이터로 교차 확인한 것이며, 공식 편람 조문 원문은 (미확인 — 접근 제약). → 경로: 한국대학교육협의회 대학정보공시센터(kcue.or.kr/work/sub08) 또는 각 대학 홈페이지에 게시된 "대학정보공시 지침서" PDF에서 확인 가능.
- **개별 대학별 교내/국가/교외 장학금 실수치 비교표**: 서울대·연세대·고려대·성균관대·부산대 등 대표 대학의 구체적 금액은 (미확인 — 접근 제약). → 경로: ① academyinfo.go.kr에서 학교명 검색 후 상세조회, 또는 ② data.go.kr의 15038576 CSV를 다운로드하여 대학명으로 필터링(가장 재현 가능성 높은 방법으로 권장).
- **"등록금 대비 장학금 비율"이 대학알리미 자체 공식 공시 항목명인지 여부**: 대학재정알리미(사학진흥재단)에서는 확인되나, 대학알리미 원 사이트에 동일 명칭의 공식 지표로 게시되는지는 (미확인 — 접근 제약).
- **2025회계연도(2026년 8월 공시 예정) 데이터**: 아직 미발표 (2026-07-24 시점 기준 최신은 2024회계연도/2025.8.29 공시분).
- **KESS의 장학금 특화 통계표**: (미확인 — 접근 제약), 경로만 3장에 기재.
- WebFetch로 접근 시 대학알리미 메인/조회 페이지는 JS 기반 대화형 UI라 정적 스크래핑으로 실제 수치가 노출되지 않음 — 향후 조사 시 공공데이터포털의 CSV/OpenAPI 경로(2장 기재)를 우선 사용할 것을 권장.

## 핵심 시사점 (편집장 전달용 3~5개)

1. 2024회계연도 기준(2025.8.29 공시) 4년제 대학생 1인당 장학금은 전국 평균 **382.7만원**(전년대비 +7.2%)이며, **사립대(403.4만원)가 국공립대(313.3만원)보다 오히려 높음** — '타대학 장학 제도' 비교 시 설립유형 간 통념(국공립이 관대할 것)과 반대되는 결과이므로 원고에 반영 필요.
2. 전국 장학금 재원 구성은 **국가장학금이 65.0%**로 압도적 비중을 차지하며 교내장학금은 31.4%에 불과 — 개별 대학의 '자체 장학 노력'을 평가하려면 총액이 아니라 **교내장학금 비중**을 별도로 봐야 함.
3. "학생 1인당 장학금"과 "학생 1인당 교육비"는 전혀 다른 지표이며 방향성도 반대로 나타남(교육비는 국공립이 더 높음) — 타 조사원 원고에 두 지표가 섞여 있는지 교차 점검 권장.
4. 개별 대학(서울대·연세대·고려대·성균관대·부산대 등) 단위의 교내/국가/교외 장학금 실수치는 이번 조사에서 확보하지 못함 — 후속 조사 필요 시 공공데이터포털 CSV(data.go.kr/data/15038576) 다운로드 후 대학명 필터링이 가장 빠른 재현 경로.
5. "등록금 대비 장학금 비율"(총장학금 지원율)은 대학알리미보다 **한국사학진흥재단 대학재정알리미(uniarlimi.kasfo.or.kr)**가 더 명확히 지표화하여 제공 — 사립대 비교 원고 작성 시 이 사이트를 1차로 활용 권장.
